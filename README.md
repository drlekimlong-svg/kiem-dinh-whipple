# Kiểm định sổ theo dõi Whipple

Trang kiểm định nội dung (vòng 1) cho sổ theo dõi người bệnh cắt khối tá tụy, khoa Ngoại, Bệnh viện An Bình.

- Mở trang: https://drlekimlong-svg.github.io/kiem-dinh-whipple/
- Người kiểm định chấm mức phù hợp 1–4 cho từng mục, ghi chú, rồi lấy file kết quả JSON ở mục "Gửi kết quả" và gửi cho người chủ trì.
- Người chủ trì mở `…/#tong-hop`, chọn các file JSON nhận được để xem I-CVI, S-CVI/Ave và tải bảng CSV.

Trang không chứa thông tin người bệnh. Điểm chấm chỉ lưu trong trình duyệt của người chấm cho tới khi họ tự gửi file.
